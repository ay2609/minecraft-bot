<task type="auto">
  <name>Task 2: Create bot entry point with EventBus wiring and spawn smoke test</name>
  <files>src/index.ts</files>
  <action>
    Replace the stub src/index.ts (created in Plan 01) with the real entry point:

    ```typescript
    import mineflayer from 'mineflayer';
    import { config } from './config';
    import { eventBus } from './events/EventBus';

    console.log('[bot] Starting minecraft-bot...');
    console.log(`[bot] Connecting to ${config.minecraft.host}:${config.minecraft.port} as ${config.minecraft.username}`);

    const bot = mineflayer.createBot({
      host: config.minecraft.host,
      port: config.minecraft.port,
      username: config.minecraft.username,
      version: config.minecraft.version,
      auth: config.minecraft.auth,
    });

    // bot.once is used for spawn (fires exactly once per connection)
    // The handler is synchronous — no floating promise risk here
    bot.once('spawn', () => {
      console.log(`[bot] Spawned as ${bot.username} on Minecraft ${bot.version}`);
      console.log(`[bot] Position: ${JSON.stringify(bot.entity.position)}`);
      eventBus.emit('bot:spawned');
      console.log('[bot] EventBus bot:spawned emitted');
    });

    // Error handler — prevents uncaught error crashes
    bot.on('error', (err: Error) => {
      console.error('[bot] Connection error:', err.message);
    });

    // End handler — log disconnect
    bot.on('end', (reason: string) => {
      console.log('[bot] Disconnected:', reason);
    });

    // Death handler — critical for Phase 7; establishing the pattern now
    bot.on('death', () => {
      console.log('[bot] Bot died');
      eventBus.emit('bot:death', {
        cause: 'unknown',
        position: {
          x: bot.entity.position.x,
          y: bot.entity.position.y,
          z: bot.entity.position.z,
        },
      });
    });

    // Chat handler — route to EventBus for Phase 8 wiring
    bot.on('chat', (username: string, message: string) => {
      if (username === bot.username) return;  // ignore own messages
      console.log(`[chat] <${username}> ${message}`);
      eventBus.emit('bot:chat', { username, message });
    });

    // Verify EventBus subscriber fires (smoke test for FOUND-03)
    eventBus.once('bot:spawned', () => {
      console.log('[eventbus] bot:spawned subscriber confirmed working');
    });

    console.log('[bot] Bot created, waiting for spawn...');
    ```

    CRITICAL no-floating-promises compliance notes:
    - bot.once('spawn', ...) callback is synchronous — no await inside, no floating promise risk
    - bot.on('error', ...) is synchronous
    - bot.on('death', ...) is synchronous
    - bot.on('chat', ...) is synchronous
    - If any handler needs async work in later phases, wrap with: `void (async () => { ... })().catch(console.error)` OR use: `bot.on('event', (...args) => { handleEvent(...args).catch(console.error); })`

    The `void` operator on a promise explicitly marks it as intentionally discarded, satisfying no-floating-promises without disabling the rule. The `.catch(console.error)` ensures errors are never silently swallowed.


    If eslint errors on `bot.entity.position` typing, add `as unknown as { x: number; y: number; z: number }` cast — mineflayer's Vec3 is compatible but TypeScript may need help.
